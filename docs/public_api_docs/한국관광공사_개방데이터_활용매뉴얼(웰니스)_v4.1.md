개방데이터 소개

한국관광공사는 국가 정보 자원의 개방 및 공유 정책에 부흥하여 아래와 같은 OpenAPI 서비스를 제공합니다.

- 국문 및 다국어(영문, 일문, 중문간체, 중문번체, 독문, 불문, 서문, 노문) 서비스 (9종)

- 국문 무장애 여행 정보 서비스

- 생태관광정보 서비스

- 관광사진갤러리 서비스

- 고캠핑정보 서비스

- 관광지 오디오 가이드정보 서비스

- 관광 빅데이터 정보 서비스

- 두루누비 정보 서비스

- 관광 채용 정보 서비스

- 관광지 집중률 방문자 추이 예측 정보 서비스

- 기초지자체 중심 관광지 정보

- 관광지별 연관 관광지 정보

- 반려동물 동반여행 서비스

- 의료 관광정보 서비스

- 웰니스 관광정보 서비스

관광정보 표출 방법

제공되는 각 API를 활용하여 관광정보 목록 및 상세정보 화면을 기획/개발하는 흐름을 설명합니다.

전체적인 관광정보 서비스 기획 및 개발 흐름의 이해를 돕고자 Guide 사이트를 운영하고 있습니다.

추가적인 정보를 원하시면 아래 사이트를 방문하시기 바랍니다.

※ 개방데이터 활용 사이트: https://data.go.kr/

지역기반 관광정보 서비스

아래 그림은 지역기반의 관광정보 목록을 서비스 하기 위해 API 활용 및 파라미터 전달하는 방법을 표현합니다.

[선택]적인 API 조회를 통해 다양하게 조합하여 목록을 표현할 수 있습니다.

상세정보 화면

국문 관광정보 서비스 API의 공통정보, 소개정보, 반복정보, 이미지 정보 조회 오퍼레이션을 활용하여 관광정보 상세정보를 제공하는 화면을 개발할 수 있습니다.

인증키 활용 및 API호출 방법

- 개발계정은 일 1,000건의 트래픽을 제공합니다.

- 개발계정은 자동승인으로 활용 신청 후, 약 10분 이후에 사용이 가능합니다.

(공공데이터포털 연동)

REST 방식의 URL 요청 예시

응답 표준은 XML 이며, JSON을 요청할 경우 “&_type=json”을 추가하여 요청합니다.

-Json 요청:

http://apis.data.go.kr/B551011/WellnessTursmService/ldongCode?serviceKey=ServiceKey&numOfRows=10&pageNo=1&MobileOS=ETC&MobileApp=TestApp&_type=json

7요청 파라미터에 서비스명 기재

MobileApp 파라미터는 서비스(웹, 앱 등)별로 활용 통계를 산출하기 위한 항목입니다.

URL 요청 시 반드시 기재 부탁드립니다.

http://apis.data.go.kr/B551011/WellnessTursmService/ldongCode?serviceKey=ServiceKey&numOfRows=10&pageNo=1&MobileOS=AND&MobileApp=appName
