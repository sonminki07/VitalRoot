1. 전사 공통 통신 원칙 & 프론트엔드 연동 가이드

모든 API 통신은 camelCase JSON 형식을 사용하며, 표준 공통 래퍼(Envelope Pattern)로 감싸서 전달됩니다.

// 성공 응답 (200 OK)
{
  "success": true,
  "data": { ... },
  "error": null
}

// 실패 응답 (에러)
{
  "success": false,
  "data": null,
  "error": {
    "code": "NOT_FOUND",
    "message": "해당 조건에 맞는 데이터를 찾을 수 없습니다."
  }
}

화면 1: 회원가입 및 온보딩 건강 프로필 (Auth & Onboarding)

Endpoint: GET /api/user/profile (조회), PUT /api/user/profile (저장)

변수명 (Key) 타입 필수 UI 표시 위치 & 컴포넌트 상세 설명 & 비즈니스 로직 예시값
userId string 필수 시스템 관리용 (비노출) 사용자 고유 UUID (Supabase Auth ID) "usr_a1b2c3d4"
userName string 필수 마이페이지 상단, 환영 문구 사용자가 설정한 닉네임 또는 본명 "김민기"
chronicConditions string[] 필수 온보딩 질환 선택 칩 태그 보유 만성질환 목록 (당뇨, 고혈압, 저혈압, 이상지질혈증, 신장질환, 관절/근골격계) ["당뇨", "고혈압"]
medications object[] 선택 복용 의약품 리스트 식약처 DUR 연계 복용 약물 목록 (id, name, ingredientName, timing, cautionNote, durWarningTags) 약품 상세 객체 리스트
walkFitnessLevel string 선택 보행 체력 슬라이더 보행 체력 수준 ("초급(완만)", "중급", "고급") "초급(완만)"
requiredInfra string[] 선택 필수 편의시설 체크박스 보행 시 3~5분 필수 편의시설 ("화장실", "쉼터", "엘리베이터", "약국") ["화장실", "쉼터"]

화면 2: 메인 탐색 & 지도 주변 안심 장소/식당 (Map & Places)

Endpoint: GET /api/places/nearby?latitude=37.3158&longitude=126.8523&radiusMeters=3000

변수명 (Key) 타입 필수 UI 표시 위치 & 컴포넌트 상세 설명 & 비즈니스 로직 공공데이터 매핑
id string 필수 장소 카드 고유 키 장소 고유 식별자 TourAPI contentid
name string 필수 장소명 타이틀 식당 또는 관광명소 명칭 TourAPI title
category string 필수 카테고리 뱃지/아이콘 장소 분류 ("안심식당", "산책로", "관광지", "의료") contentTypeId / cat3
address string 필수 주소 텍스트, 길찾기 복사 기본 도로명 또는 지번 주소 TourAPI addr1
latitude number 필수 네이버 지도 마커 핀 위도 GPS 좌표 (Y축) TourAPI mapy
longitude number 필수 네이버 지도 마커 핀 경도 GPS 좌표 (X축) TourAPI mapx
imageUrl string | null 선택 장소 썸네일/대표 이미지 대표 사진 URL (없을 시 null) TourAPI firstimage
safeTags string[] 필수 안심 인증 태그 칩 안심식당 및 무장애 편의시설 검증 태그 TourAPI detailWithTour2
nutrition object | null 선택 식당 영양성분 아코디언 식약처 식품영양성분 (calories, carbohydrate, sugars, sodium, sugarGrade, sodiumGrade) 식약처 식품영양 DB

화면 3: 질환 맞춤형 식후 걷기 추천 코스 (Course Recommendation)

Endpoint: GET /api/courses/recommend?condition=당뇨

변수명 (Key) 타입 필수 UI 표시 위치 & 컴포넌트 상세 설명 & 비즈니스 로직 예시값
id string 필수 코스 식별자 코스 고유 ID "course_ansan_01"
title string 필수 코스 헤더 타이틀 코스 기획 명칭 "식후 혈당 케어 안산 호수공원 완보길"
totalDistanceMeters number 필수 총 보행 거리 (1.8km) TMap 보행자 API 기반 실제 보행 도로망 거리 (단위: m) 1850
walkMinutes number 필수 소요 시간 (28분) 시니어 보행 속도 기준 완보 예상 시간 (단위: 분) 28
slopeGrade string 필수 난이도 뱃지 경사도 등급 ("완만(무장애)", "보통", "도전") "완만(무장애)"
walkingRoute [number, number][] 필수 지도 위 경로 폴리라인 GeoJSON 도로망 좌표 배열 [[lng, lat], ...] [[126.834, 37.301], ...]
waypoints object[] 선택 경로 상 편의시설 마커 동선 3~5분 공공 편의시설 리스트 (화장실, 쉼터 등) 편의시설 상세 리스트

화면 4: 1박 2일 웰니스 안심 숙소 (Wellness Stays)

Endpoint: GET /api/stays

변수명 (Key) 타입 필수 UI 표시 위치 & 컴포넌트 상세 설명 & 비즈니스 로직 공공데이터 매핑
id string 필수 숙소 카드 키 숙소 고유 ID TourAPI contentid
name string 필수 숙소명 타이틀 숙박 시설 명칭 TourAPI title
chkCooking boolean 필수 취사 가능 뱃지 객실 내 취사 가능 여부 (저염식 환자 자가 조리) detailIntro2 chkcooking
roomRefrigerator boolean 필수 냉장고 보유 뱃지 객실 내 냉장고 보유 여부 (인슐린 보관 필수) detailIntro2 roomrefrigerator
hasFitness boolean 필수 피트니스 뱃지 헬스장/체력단련실 보유 여부 (식후 혈당 루틴) detailIntro2 fitness

화면 5: 관광명소 퀘스트 & 실시간 GPS 완보 세션 (Quest & Walk Session)

Endpoint: POST /api/walk-session/ping (주기적 동기화), POST /api/walk-session/complete (완보 완료)

변수명 (Key) 타입 필수 UI 표시 위치 & 컴포넌트 상세 설명 & 비즈니스 로직 예시값
questId string 필수 퀘스트 식별자 퀘스트 고유 ID "qst_reed_wetland"
targetName string 필수 상단 위젯 목적지 명칭 완보 목표 관광명소 명칭 "안산 갈대습지공원"
targetDurationMinutes number 필수 목표 시간 (20분) 완보 인정에 필요한 최소 산책 시간 (분) 20
titleReward string 필수 획득 칭호 뱃지 완보 성공 시 지급되는 리워드 칭호 "갈대습지 생태 수호자"
elapsedSeconds number 필수 원형 프로그레스바 타이머 현재까지 누적된 실제 보행 시간 (단위: 초) 720
isGpsValid boolean 필수 GPS 연결 상태 신호등 사용자가 명소 반경 500m 이내 정상 체류 중인지 여부 true
isEligible boolean 필수 완보 인증 버튼 활성화 목표 시간 이상 체류하여 리워드 획득 자격을 갖췄는지 여부 false
