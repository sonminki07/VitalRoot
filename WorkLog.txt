# VitalRoot 작업 로그 (WorkLog)

## [2026-09-20] 사용자 피드백 16대 요구사항 마스터 기술 기획서 (Master Implementation Specification) 작성 완료

### 1. 작업 개요
- 사용자가 첨부한 5장의 스크린샷과 피드백 항목(알레르기 수정 불가, 칭호 획득 무조건 성공 버그, 상단 노트북 UI 겹침, 길찾기 핀 오차, 팝업 X 버튼 부재 및 투명도, 스크롤바 디자인, 지역별 코스 고정 문제, 글자 크기, 테마, 버튼 정돈 등 총 16대 사항) 정밀 분석.
- 후속 작업 모델(Worker Model)이 프롬프트로 전달받아 추가 질의 없이 100% 즉시 코드로 구현할 수 있도록 코드 레벨 가이드라인을 포함한 마스터 기획서 아티팩트(`master_specification_plan.md`, `implementation_plan.md`) 구축.

### 2. 핵심 사양 정리
1. **알레르기 정보 수정**: `SettingsModal.tsx` 탭 1에 알레르기 식품 8종 토글 신설 및 실시간 영속화.
2. **지역 코스 다변화**: 고양시(일산호수공원, 행주산성), 수원시(광교), 성남시(율동) 코스 확충 및 좌표 기준 최근접 매칭.
3. **칭호 획득 검증**: 비로그인 차단 + 명소 반경 300m GPS 거리 검증 로직 구현.
4. **지도 핀 앵커 오차 보정 (이미지 1)**: 가변 너비 중앙 정렬(`-translate-x-1/2`) 및 핀 끝점 앵커 정밀 고정.
5. **마커 팝업 개선 (이미지 2, 4)**: 우측 상단 닫기 [✕] 버튼 추가 및 `backdrop-blur` 글래스모피즘 적용으로 뒷배경 투과.
6. **모달 활성화 시 지도 컨트롤 딤 (이미지 3)**: 모달 오픈 시 줌 컨트롤/로고에 `opacity-20 pointer-events-none` 부여.
7. **스크롤바 커스텀 (이미지 5)**: `index.css`에 6px 에메랄드 다크 스크롤바 구현.
8. **버튼 정돈 (이미지 5)**: 코스 카드 하단 버튼을 2x2 정돈 그리드로 재배치.
9. **기타 기능**: 글자 크기 조절, 다크/화이트 테마, 거리 단위 변환(m/km), 지도 타입 영속화, 나만의 코스 저장 기반.

### 3. 산출물
- `master_specification_plan.md`: 다른 모델에게 즉시 인계 가능한 16대 항목별 코드 레벨 작업 지시서.
- `implementation_plan.md`: 전체 아키텍처 및 구현 로드맵.
